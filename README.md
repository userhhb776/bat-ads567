# Bat Ads567

é tudo para uso pessoal... é que meu computador trava muito quando tento acessar o gerenciador de anuncios então decidi criar esse app pessoal para me ajudar nisso... ele terá uma parte ali de criar anuncio (que vai seguir uma aba bem parecida como a dashboard real da meta tendo todas as funções e etc da publicação real e oficial... e ele também terá meio que sua propria utmfy que vai me ajudar a analisar metricas, conectar os gateways e etc... vai ser meio que um "clone" pessoal da meta para eu poder gerenciar os anúncios e etc... ou seja ela terá duas "abas" uma de modo MET e outra de mfo UTM para tentar ser quase igual a ferramenta original (apenas mudando nomes para não ter problemas de direitos autorais).

Não quero usar lovable cloud... usarei um supabase externo para poder ter o banco de dados caso necessário.
Além disso vi também um repositório que pode nos ajudar: https://github.com/gabipogere-sys/tracking-template.git
Aqui tem vários arquivos que talvez você possa pegar já prontos e por aqui. Mas faça isso só se ele bater com o que eu te pedi... Não faça nada diferente do que o que eu te pedi.
